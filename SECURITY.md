# Security Policy

## Supported versions

Only the latest release on the App Store receives fixes.

## Reporting a vulnerability

Please don't report security problems in public issues. Instead, use GitHub's [private vulnerability reporting](https://github.com/ellisandy/FormationFlight/security/advisories/new), or email jack@mnmlst.cc.

Include what you found, how to reproduce it, and the app and iOS versions. You should get a reply within a week.

Formation Flight has no servers, accounts, or network access, and stores only your saved flights and settings on the device, so most reports are likely to concern on-device data handling or location use.
